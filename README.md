# 🚀 Auto Deploy Site

A collection of reusable frontend templates and static web pages designed for rapid website development and automated site deployment.

---

## 📋 Overview

**Auto Deploy Site** is a multi-purpose frontend template repository containing a large collection of ready-to-use HTML pages, stylesheets, JavaScript files, and visual assets.

The repository can be used as:

* A reusable UI template library
* A collection of frontend page designs
* A foundation for building different types of websites
* A source for automated site generation and deployment

The `generated_site/` directory contains a standalone/generated version of the website.

---

## 🛠️ Technologies Used

* **HTML5** — Page structure and content
* **CSS3** — Styling and layouts
* **JavaScript** — Client-side functionality and interactions
* **YAML** — Configuration files

## ⚙️ How to Use

### 1. Clone the Repository

```bash
git clone <repository-url>
cd Auto-Deploy-Site
```

### 2. Open the Website

Since this is a static frontend project, you can open:

```text
index.html
```

directly in your web browser.

---

### 3. Explore the Templates

You can open any `.html` file to preview a specific template.

For example:

```text
products.html
doctor-profile.html
admin-dashboard.html
courses.html
```

---

### 4. Check the Generated Site

The `generated_site/` directory contains the generated/standalone version of the website.

```text
generated_site/
├── HTML pages
├── CSS files
└── JavaScript files
```
